# 🎯 Deployment a Replit (100% GRATUITO)

## Paso 1: Crear Cuenta en Replit

1. Ve a: **https://replit.com**
2. Click en **Sign up**
3. Usa GitHub para sign up
4. Autoriza Replit

## Paso 2: Importar desde GitHub

1. En Replit, click en **Create** (arriba)
2. Click en **Import from GitHub**
3. Pega tu repo URL:
   ```
   https://github.com/ramsja/dashboard-Genius
   ```
4. Selecciona rama: **claude/estructura-estudio-kozee8**
5. Click **Import**

## Paso 3: Configurar Replit

1. Replit detectará que es Node.js
2. En la raíz, crea archivo `.replit`:
   ```
   run = "node server-simple.js"
   ```
3. Click en **Run** (botón verde arriba)

## Paso 4: El servidor inicia

```
🚀 Listening on http://0.0.0.0:3000
```

## Paso 5: Obtener URL Pública

- Replit genera automáticamente una URL pública:
  ```
  https://dashboard-genius-xxxx.replit.dev
  ```
- Esta URL aparece en la parte superior
